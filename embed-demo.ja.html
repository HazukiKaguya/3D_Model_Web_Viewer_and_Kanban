3D モデルを Web ページに埋め込む看板娘デモ

左のキャラクターが埋め込みビューアです — フローティングレイヤー自体は普段は完全に見えず（ポインターが入ったときだけ枠と影が出ます）。そのためキャラクターがページ上に直接立っているように見えます。キャラクター本体をドラッグするとパネル全体が移動します， 右ボタンでドラッグするとキャラクターが回転します。左ボタンを押している間、ページは play3dmodelaction を呼び出し Formation_Pickup、離すと元に戻ります。

1. コンテナ 1 つ + script 2 行で使えます

<!-- data-ba3d-drag で「キャラクターを左ドラッグしてコンテナ移動」を有効化 -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<script type="module">
  import { autoMount } from './dist/3d-viewer.min.js';  // 自己完結の単一ファイル版（importmap 不要）
  autoMount();
</script>

キャラクターによっては「倒れ / 死亡」のように下へ広がるモーションがあるため、埋め込み時の既定のフレーミングオフセットは 42 です。カードが低いときやモーションが大きいときにキャラクターが画面外へ出ないようにします。その場合はコンテナに data-ba3d-framing-offset を書きます。値が大きいほど画面は上へ移動し、下の余白が増えます。 

<!-- 既定 42（属性の指定は不要） -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<!-- もう少し上へ：数値を明示（単位はコンテナの CSS ピクセル） -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     data-ba3d-framing-offset="70"
     style="width:420px;height:430px"></div>

<!-- まったく下げない -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     data-ba3d-framing-offset="0"
     style="width:420px;height:430px"></div>

⚠️注意：同じ値でも高さの違うコンテナでは効果が異なります（コンテナ高でワールド単位に換算されます）。サイズ変更後は再確認してください。

2. コンテナの data-* 属性

属性説明
data-ba3dこのコンテナにビューアを付けることを示します
data-ba3d-config設定 JSON（モデル / 口元テクスチャ / 基準 / レンダー / ライティング / 背景）
data-ba3d-modelモデルファイル URL（.glb）
data-ba3d-mouth口元補正テクスチャ URL（.png）
data-ba3d-framing-offsetフレーミングの垂直オフセット（CSS px · 正 = フレーミング下げ ⇒ 内容は上へ）。埋め込み既定 42 。倒れ / 死亡のように下へ広がるモーションがあるときは大きくすると下の余白が増えます。
⚠️ コンテナ高で換算されます。サイズ変更後は再確認してください。例は上の 1 節を参照。
data-ba3d-grid地面グリッドを表示（既定はオフ · 埋め込み看板娘では通常不要）
data-ba3d-axes原点 XYZ 軸を表示（既定はオフ）
data-ba3d-gizmo視点インジケーターを表示（既定はオフ）
data-ba3d-light-helperメインライト方向の表示（既定はオフ）
data-ba3d-drag「モデル上で左ドラッグしてコンテナを移動」を有効化
data-ba3d-auto-rotatetrue 自動回転

3. パネルサイズ：パーセントで変えると全体が比例して拡大/縮小

設定のフレーミング関連フィールド：

フィールド説明
renderer.framing "tight" = 使用：実際のスキン内容で中央合わせ（ボックス基準の中央/接地は誤りで、キャラクターが偏って浮きます）
renderer.framingReferenceHeight 参照パネル高さ。カメラパラメータはこれを基準に一度固定ワールド値 として計算されます — そのためパネルをパーセントで変えると画面全体が比例して拡大/縮小します（キャラクターの大きさと相対位置が一緒に変わります）。この例では 430（パネル高さ）を使用
renderer.framingOffsetY フレーミングの垂直オフセット（単位 CSS px、参照高さ基準）。正 = フレーミング下げ / 画面内容は上へ。倒れるモーションは内容を画面下に寄せるため、57px 下げて上下の余白を揃えます

そのためコンテナのサイズを比例で変えるだけで、他のパラメータは触る必要がありません：

<!-- 元（参照）サイズ -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<!-- 1.5 倍に拡大 -->
<div ... style="width:630px;height:645px"></div>

<!-- 60% に縮小 -->
<div ... style="width:252px;height:258px"></div>

<!-- パーセントやレスポンシブ単位でも可 -->
<div ... style="width:50vh;height:51vh"></div>

モデルが小さすぎる/大きすぎる場合は、設定を変えずにホイールでモデルを拡大/縮小 してください。

4. 操作方法の約束

操作動作
左ボタンをモデル上でドラッグコンテナ全体を移動（必要： data-ba3d-drag）
右ボタンをモデル上でドラッグキャラクターを回転（左ボタンでは回転しません）
ホイール拡大/縮小

押し続けて初めて「押下」：0.2s しきい値

モデル上で左ボタンを押した後すぐには発火せず、待機状態になり、次の時間を超えると pressHoldMs（既定 200ms） で初めて「押下」となり、そのとき ba3d:press が発行されてコンテナのドラッグが始まります。 押し足りずに離すと「クリック」として ba3d:click を発行し、ドラッグはしません。

これで一度クリックしてモーションを出そうとしてパネルを動かしてしまう状況は起きません。

panel.addEventListener('ba3d:press', (e) => {
  // e.detail = { button, heldMs, thresholdMs, hit }   長押し成立 → モーション発動
});
panel.addEventListener('ba3d:click', (e) => {
  // e.detail = { button, heldMs, thresholdMs, hit }   短押し → クリック扱い
});

すべての押下/解除はコンテナ上でバブリングする CustomEvent として発行されるため、ページで直接購読できます：

panel.addEventListener('ba3d:pointerdown', (e) => {
  // e.detail = { button, hit }                        hit = モデル上で押したか（しきい値なしで即発行）
});
panel.addEventListener('ba3d:pointerup', (e) => {
  // e.detail = { button, hit, pressedOnModel, pressed }
  //   pressed = 今回ホールドしきい値を超えたか（true=押下 / false=クリックのみ）
});

5. モーション連携：play3dmodelaction([动作数组])

play3dmodelaction(['Formation_Pickup']);   // 一致した最初のモーションを再生
play3dmodelaction(['A', 'B']);             // 順番に探し、存在する最初のものを再生
play3dmodelaction([3]);                    // インデックスでも可
play3dmodelaction('Cafe_Idle');            // 単一の文字列でも可
play3dmodelaction();                       // 引数なし → 既定モーションへ（ランダム idle）

一致規則：完全一致 → 大文字小文字を無視した完全一致 → 「名前を含む」（大文字小文字無視）。 そのため 'Formation_Pickup' は次に一致します： xxx_Formation_Pickup。

左下の操作エリアのモーション選択

左下の操作エリア最上段のドロップダウンは純粋なページ側コードです。モーション一覧をビューアに一度問い合わせ、モーションの切り替えはグローバルフックのみを使い、 モデル内部には一切触れません：

const sel = document.getElementById('animSel');
let current = null;

// 1) モーション一覧でメニューを埋める
for (const a of viewer.getAnimations()) {
  const o = document.createElement('option');
  o.value = a.name;
  o.textContent = a.name.replace(/^[^_]*_/, '');
  sel.appendChild(o);
}
// 2) ビューアの ba3d:action を購読して選択を同期（内部状態は読まない）
panel.addEventListener('ba3d:action', (e) => { sel.value = current = e.detail.name; });

// 3) 切り替え = グローバルフックを呼ぶ（戻り値は実際に再生したモーション名）
sel.addEventListener('change', () => {
  const played = play3dmodelaction([sel.value]);
  if (played) current = played;
});

左ボタンの押下/解除も同じ current を使うので、「押下で Pickup → 解除で復帰」の復帰先は メニューで選んだモーションそのものです。

このページのテストコード（左下のログで動いている部分）：

const panel = document.getElementById('floatPanel');
let prevAction = null;

// ≥200ms のホールドで初めて「押下」
panel.addEventListener('ba3d:press', (e) => {
  if (e.detail.button !== 0) return;
  prevAction = current;                                 // メニューの選択を覚える
  play3dmodelaction(['Formation_Pickup']);              // 押下：モーション発動
});

// 短押しはクリック扱いで押下しない
panel.addEventListener('ba3d:click', (e) => {
  console.log('点击，按住', e.detail.heldMs, 'ms / 阈值', e.detail.thresholdMs, 'ms');
});

panel.addEventListener('ba3d:pointerup', (e) => {
  if (e.detail.button !== 0 || !e.detail.pressed) return;   // 本当に押下したときだけ復帰
  play3dmodelaction(prevAction ? [prevAction] : undefined); // 引数なし = 既定モーションへ
});

6. 既定のモーション

設定に animation.name がない場合、名前含む idle モーションからランダムに選んで初期モーションにします （このモデルには Normal_Idle / Cafe_Idle / Formation_Idle 個あります）。 何度か再読み込みすると初期モーションが変わります。

7. JS から作成しても等価です

import { createViewer } from './dist/3d-viewer.min.js';

const viewer = createViewer(document.getElementById('floatPanel'), {
  modelUrl:       './assets/sample.glb',
  mouthAtlasUrl:  './assets/mouth/Character_Mouth_High.png',
  configUrl:      './assets/sample.json',   // オブジェクトを直接渡しても可：config: {...}
  dragContainer:  true,              // モデル上で左ドラッグしてコンテナ移動
  backgroundTransparent: true,
});
await viewer.load();
viewer.playAction(['Formation_Pickup']);

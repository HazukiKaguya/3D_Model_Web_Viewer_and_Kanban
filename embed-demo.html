3D 模型网页内嵌看板娘演示

左边那个角色就是内嵌的查看器 —— 浮层本身**平时完全隐形**（鼠标移进它的范围才显出边框和投影）， 所以看起来就像角色直接站在网页上。按住角色本体拖动可以移动整个面板， 按住右键拖动可以旋转角色。按住左键时页面会通过 play3dmodelaction 触发 Formation_Pickup，松开恢复。

1. 放一个容器 + 两行 script 就能用

<!-- data-ba3d-drag 开启「左键按角色拖容器」 -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<script type="module">
  import { autoMount } from './dist/ba3d-viewer.min.js';  // 自包含单文件版，无需 importmap
  autoMount();
</script>

2. 容器的 data-* 属性

属性说明
data-ba3d标记这个容器要挂查看器
data-ba3d-config配置 JSON（模型 / 嘴部贴图 / 基准 / 渲染 / 打光 / 背景）
data-ba3d-model模型文件 URL（.glb）
data-ba3d-mouth嘴部修复贴图 URL（.png）
data-ba3d-drag开启「左键按在模型上拖动整个容器」
data-ba3d-auto-rotatetrue 自动旋转

3. 面板尺寸：按百分比改就是整体等比缩放

配置里的取景相关字段：

字段说明
renderer.framing "tight" = 用真实蒙皮内容居中（整盒的居中/落地是错的，会让角色偏心 + 悬空）
renderer.framingReferenceHeight 参考面板高度。相机参数按它一次算成固定世界量 —— 于是面板按百分比缩放时，画面整体等比缩放（角色尺寸和相对位置一起变）。本例选 430（面板高度）
renderer.framingOffsetY 取景垂直偏移，单位 CSS 像素（以参考高度为准），正值 = 取景下移 / 画面内容上移。倒地类动作会把内容压在画面下方，下移 57px 把上下余量拉平

所以把容器尺寸按比例改一下就行，不需要动任何其它参数：

<!-- 原始（参考）尺寸 -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<!-- 放大 1.5 倍 -->
<div ... style="width:630px;height:645px"></div>

<!-- 缩小到 60% -->
<div ... style="width:252px;height:258px"></div>

<!-- 或者用百分比 / 响应式单位也行 -->
<div ... style="width:50vh;height:51vh"></div>

载入模型时若觉得太小/太大，不用改配置，直接滚动滚轮缩放模型即可。

4. 交互约定

操作行为
左键按在模型身上拖动移动整个容器（需 data-ba3d-drag）
右键按在模型身上拖动旋转角色（左键不再旋转）
滚轮缩放

按住才算「按下」：0.2s 阈值

左键在模型上按下后**不会立刻**触发——先进入待定，按住超过 pressHoldMs（默认 200ms） 才真正算一次「按下」，这时才会派发 ba3d:press 并开始拖动容器； 没按够就松手算「点击」，派发 ba3d:click，不触发拖动。

这样**点一下想触发动作、结果把面板拖走了**的情况就不会发生了。

panel.addEventListener('ba3d:press', (e) => {
  // e.detail = { button, heldMs, thresholdMs, hit }   按住够久了 → 触发动作
});
panel.addEventListener('ba3d:click', (e) => {
  // e.detail = { button, heldMs, thresholdMs, hit }   短按 → 算点击
});

所有按下/抬起都会在容器上派发冒泡的 CustomEvent，页面直接监听即可：

panel.addEventListener('ba3d:pointerdown', (e) => {
  // e.detail = { button, hit }                        hit=是否按在模型身上（立即派发，不过阈值）
});
panel.addEventListener('ba3d:pointerup', (e) => {
  // e.detail = { button, hit, pressedOnModel, pressed }
  //   pressed = 本次是否越过了按住阈值（true=按下过 / false=只是点击）
});

5. 动作钩子：play3dmodelaction([动作数组])

play3dmodelaction(['Formation_Pickup']);   // 播第一个能匹配到的动作
play3dmodelaction(['A', 'B']);             // 按顺序找，播第一个存在的
play3dmodelaction([3]);                    // 也可以用索引
play3dmodelaction('Cafe_Idle');            // 单个字符串也行
play3dmodelaction();                       // 不传 → 回到默认动作（随机 idle）

匹配规则：精确名字 → 忽略大小写精确 → 「名字包含」（忽略大小写）。 所以 'Formation_Pickup' 能匹配到 xxx_Formation_Pickup。

左下角控件区的动作选单

左下角控件区最上面那行的下拉选单就是纯页面代码：动作列表问一次查看器，**切动作只走全局钩子**， 完全不碰模型内部：

const sel = document.getElementById('animSel');
let current = null;

// 1) 用动作列表填充选单
for (const a of viewer.getAnimations()) {
  const o = document.createElement('option');
  o.value = a.name;
  o.textContent = a.name.replace(/^[^_]*_/, '');
  sel.appendChild(o);
}
// 2) 监听查看器的 ba3d:action 事件来同步选中项（不读查看器内部状态）
panel.addEventListener('ba3d:action', (e) => { sel.value = current = e.detail.name; });

// 3) 切换 = 调全局钩子（返回值是实际播上的动作名）
sel.addEventListener('change', () => {
  const played = play3dmodelaction([sel.value]);
  if (played) current = played;
});

左键按下/抬起也用同一个 current，所以「按下触发 Pickup → 抬起恢复」恢复的 正是你在选单里选的那一段。

本页测试代码（就是左下角日志里跑的那段）：

const panel = document.getElementById('floatPanel');
let prevAction = null;

// 按住 ≥200ms 才算「按下」
panel.addEventListener('ba3d:press', (e) => {
  if (e.detail.button !== 0) return;
  prevAction = current;                                 // 记住选单里选的
  play3dmodelaction(['Formation_Pickup']);              // 按下：触发动作
});

// 短按算点击，不触发按下
panel.addEventListener('ba3d:click', (e) => {
  console.log('点击，按住', e.detail.heldMs, 'ms / 阈值', e.detail.thresholdMs, 'ms');
});

panel.addEventListener('ba3d:pointerup', (e) => {
  if (e.detail.button !== 0 || !e.detail.pressed) return;   // 只有真的按下过才恢复
  play3dmodelaction(prevAction ? [prevAction] : undefined); // 不带参 = 回默认动作
});

6. 默认动作

配置里没写 animation.name 时，会**在名字含 idle 的动作里随机**挑一个作为初始动作 （本模型有 Normal_Idle / Cafe_Idle / Formation_Idle 三个）。 多刷新几次能看到初始动作在变。

7. 也可以用 JS 创建（等价）

import { createViewer } from './dist/ba3d-viewer.min.js';

const viewer = createViewer(document.getElementById('floatPanel'), {
  modelUrl:       './assets/sample.glb',
  mouthAtlasUrl:  './assets/mouth/Character_Mouth_High.png',
  configUrl:      './assets/sample.json',   // 也可直接传对象：config: {...}
  dragContainer:  true,              // 左键按模型拖容器
  backgroundTransparent: true,
});
await viewer.load();
viewer.playAction(['Formation_Pickup']);

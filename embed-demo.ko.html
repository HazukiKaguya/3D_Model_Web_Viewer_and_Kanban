3D 모델 웹 내장 마스코트 데모

왼쪽 캐릭터가 바로 내장된 뷰어입니다 — 플로팅 레이어 자체는평소에는 완전히 보이지 않으며(마우스를 올려야 테두리와 그림자가 나타납니다), 그래서 캐릭터가 웹 페이지 위에 그대로 서 있는 것처럼 보입니다.캐릭터 본체를 잡고 끌면 패널 전체가 이동합니다， 오른쪽 버튼을 누른 채 끌면 캐릭터가 회전합니다. 왼쪽 버튼을 누르면 페이지가 play3dmodelaction 을(를) 호출해 Formation_Pickup 를 재생하고, 놓으면 원래대로 돌아갑니다.

1. 컨테이너 하나 + script 두 줄이면 사용 가능

<!-- data-ba3d-drag 로 「캐릭터를 왼쪽 드래그해 컨테이너 이동」 켜기 -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<script type="module">
  import { autoMount } from './dist/3d-viewer.min.js';  // 자체 완결 단일 파일 판(importmap 불필요)
  autoMount();
</script>

캐릭터에 「쓰러짐 / 사망」처럼 아래로 펼쳐지는 모션이 있는 경우가 있어, 임베드 기본 프레이밍 오프셋은 42 입니다. 카드가 더 낮거나 모션 폭이 클 때 캐릭터가 장면 밖으로 나가지 않게 하며, 이때 컨테이너에 data-ba3d-framing-offset 를 쓰면 됩니다. 값이 클수록 화면이 위로 가고 아래 여백이 늘어납니다. 

<!-- 기본 42(속성 불필요) -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<!-- 조금 더 위로: 값을 직접 지정(단위: 컨테이너 CSS 픽셀) -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     data-ba3d-framing-offset="70"
     style="width:420px;height:430px"></div>

<!-- 전혀 내리지 않음 -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     data-ba3d-framing-offset="0"
     style="width:420px;height:430px"></div>

⚠️주의: 같은 값이라도높이가 다른 컨테이너에서는 효과가 다릅니다(컨테이너 높이로 월드 단위를 환산). 크기를 바꾼 뒤 다시 시험하세요.

2. 컨테이너의 data-* 속성

속성설명
data-ba3d이 컨테이너에 뷰어를 붙이도록 표시
data-ba3d-config설정 JSON(모델 / 입가 텍스처 / 기준 / 렌더 / 라이팅 / 배경)
data-ba3d-model모델 파일 URL(.glb）
data-ba3d-mouth입가 보정 텍스처 URL(.png）
data-ba3d-framing-offset프레이밍 수직 오프셋(CSS 픽셀 · 양수 = 구도 하향 ⇒ 내용 상향). 임베드 기본값 42 . 쓰러짐/사망처럼 아래로 펼쳐지는 모션이 있으면 값을 키우면 아래 여백이 늘어납니다.
⚠️ 컨테이너 높이로 환산되므로 크기를 바꾼 뒤 다시 시험하세요. 예시는 위 1 절 참고.
data-ba3d-grid바닥 그리드 표시(기본 꺼짐 · 임베드 마스코트에는 보통 불필요)
data-ba3d-axes원점 XYZ 축 표시(기본 꺼짐)
data-ba3d-gizmo시점 표시기 표시(기본 꺼짐)
data-ba3d-light-helper메인 라이트 방향 표시(기본 꺼짐)
data-ba3d-drag「모델 위에서 왼쪽 버튼으로 컨테이너 이동」 켜기
data-ba3d-auto-rotatetrue 자동 회전

3. 패널 크기: 퍼센트로 바꾸면 전체가 비례해서 확대/축소됩니다

설정의 프레이밍 관련 필드:

필드설명
renderer.framing "tight" = 사용:실제 스킨 내용기준 중앙 정렬(박스 기준 중앙/접지는 잘못되어 캐릭터가 치우치고 떠 보입니다)
renderer.framingReferenceHeight 참조 패널 높이. 카메라 파라미터는 이를 기준으로 한 번고정 월드 값 으로 계산됩니다 — 그래서 패널을 퍼센트로 조정하면 화면 전체가 비례해 확대/축소됩니다(캐릭터 크기와 상대 위치가 함께 변함). 이 예시는 430(패널 높이) 선택
renderer.framingOffsetY 프레이밍 수직 오프셋, 단위 CSS 픽셀(참조 높이 기준), 양수 = 구도 하향 / 화면 내용 상향. 쓰러짐 모션은 내용을 화면 아래로 누르므로 57px 내려 위아래 여백을 맞춥니다

그래서 컨테이너 크기만 비례로 바꾸면 되고, 다른 파라미터는 건드릴 필요가 없습니다:

<!-- 원래(참조) 크기 -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<!-- 1.5배 확대 -->
<div ... style="width:630px;height:645px"></div>

<!-- 60%로 축소 -->
<div ... style="width:252px;height:258px"></div>

<!-- 퍼센트 / 반응형 단위도 가능 -->
<div ... style="width:50vh;height:51vh"></div>

모델이 너무 작거나 크면,설정을 고치지 말고 휠로 모델을 확대/축소 하면 됩니다.

4. 상호작용 규약

조작동작
왼쪽 버튼을모델 위에서끌기컨테이너 전체 이동(필요: data-ba3d-drag）
오른쪽 버튼을모델 위에서끌기캐릭터 회전(왼쪽 버튼은 더 이상 회전하지 않음)
휠확대/축소

눌러야 「누름」: 0.2s 임계값

모델 위에서 왼쪽 버튼을 누른 뒤즉시발동하지 않고 대기 상태가 되며, 다음 시간을 넘기면 pressHoldMs(기본 200ms) 에야 실제 「누름」이 되고, 그때 ba3d:press 이(가) 발생하며 컨테이너 드래그가 시작됩니다; 충분히 누르지 않고 놓으면 「클릭」으로 보고 ba3d:click 를 발생시키며 드래그는 하지 않습니다.

이렇게 하면한 번 클릭해 모션을 발동하려다 패널을 끌어버리는 상황이 생기지 않습니다.

panel.addEventListener('ba3d:press', (e) => {
  // e.detail = { button, heldMs, thresholdMs, hit }   충분히 누름 → 모션 발동
});
panel.addEventListener('ba3d:click', (e) => {
  // e.detail = { button, heldMs, thresholdMs, hit }   짧게 누름 → 클릭 처리
});

모든 누름/놓기는 컨테이너에서버블링되는 CustomEvent 를 발생시키므로 페이지에서 바로 들을 수 있습니다:

panel.addEventListener('ba3d:pointerdown', (e) => {
  // e.detail = { button, hit }                        hit = 모델 위를 눌렀는지(임계값 없이 즉시 발생)
});
panel.addEventListener('ba3d:pointerup', (e) => {
  // e.detail = { button, hit, pressedOnModel, pressed }
  //   pressed = 이번에 누름 임계값을 넘었는지(true=눌림 / false=클릭뿐)
});

5. 모션 훅:play3dmodelaction([动作数组])

play3dmodelaction(['Formation_Pickup']);   // 매칭되는 첫 모션 재생
play3dmodelaction(['A', 'B']);             // 순서대로 찾아 존재하는 첫 것을 재생
play3dmodelaction([3]);                    // 인덱스도 가능
play3dmodelaction('Cafe_Idle');            // 단일 문자열도 가능
play3dmodelaction();                       // 인자 없음 → 기본 모션(랜덤 idle)

매칭 규칙: 정확한 이름 → 대소문자 무시 정확 → 「이름 포함」(대소문자 무시). 그래서 'Formation_Pickup' 는 다음에 매칭됩니다: xxx_Formation_Pickup。

좌하단 컨트롤 영역의 모션 선택

좌하단 컨트롤 영역 맨 위 줄의 드롭다운은 순수 페이지 코드입니다: 모션 목록을 한 번 뷰어에 묻고,모션 전환은 전역 훅으로만 , 모델 내부는 전혀 건드리지 않습니다:

const sel = document.getElementById('animSel');
let current = null;

// 1) 모션 목록으로 메뉴 채우기
for (const a of viewer.getAnimations()) {
  const o = document.createElement('option');
  o.value = a.name;
  o.textContent = a.name.replace(/^[^_]*_/, '');
  sel.appendChild(o);
}
// 2) 뷰어의 ba3d:action 이벤트로 선택 항목 동기화(내부 상태는 읽지 않음)
panel.addEventListener('ba3d:action', (e) => { sel.value = current = e.detail.name; });

// 3) 전환 = 전역 훅 호출(반환값은 실제 재생된 모션 이름)
sel.addEventListener('change', () => {
  const played = play3dmodelaction([sel.value]);
  if (played) current = played;
});

왼쪽 버튼 누름/놓기도 같은 current 을(를) 쓰므로, 「누르면 Pickup → 놓으면 복귀」의 복귀 대상은 바로 선택 메뉴에서 고른 모션입니다.

이 페이지의 테스트 코드(좌하단 로그에서 도는 부분):

const panel = document.getElementById('floatPanel');
let prevAction = null;

// ≥200ms 눌러야 「누름」
panel.addEventListener('ba3d:press', (e) => {
  if (e.detail.button !== 0) return;
  prevAction = current;                                 // 메뉴에서 고른 것을 기억
  play3dmodelaction(['Formation_Pickup']);              // 누름: 모션 발동
});

// 짧게 누르면 클릭으로 보고 누름은 발생하지 않음
panel.addEventListener('ba3d:click', (e) => {
  console.log('点击，按住', e.detail.heldMs, 'ms / 阈值', e.detail.thresholdMs, 'ms');
});

panel.addEventListener('ba3d:pointerup', (e) => {
  if (e.detail.button !== 0 || !e.detail.pressed) return;   // 실제로 눌렀을 때만 복귀
  play3dmodelaction(prevAction ? [prevAction] : undefined); // 인자 없음 = 기본 모션
});

6. 기본 모션

설정에 animation.name 이 없으면,이름에 idle 가 들어간 모션 중에서 무작위로골라 초기 모션으로 사용합니다 (이 모델에는 Normal_Idle / Cafe_Idle / Formation_Idle 세 개). 새로고침을 몇 번 하면 초기 모션이 바뀌는 것을 볼 수 있습니다.

7. JS 로 직접 생성도 가능(동등)

import { createViewer } from './dist/3d-viewer.min.js';

const viewer = createViewer(document.getElementById('floatPanel'), {
  modelUrl:       './assets/sample.glb',
  mouthAtlasUrl:  './assets/mouth/Character_Mouth_High.png',
  configUrl:      './assets/sample.json',   // 객체를 직접 넘겨도 됨: config: {...}
  dragContainer:  true,              // 모델 위에서 왼쪽 드래그로 컨테이너 이동
  backgroundTransparent: true,
});
await viewer.load();
viewer.playAction(['Formation_Pickup']);

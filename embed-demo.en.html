3D model web-embed mascot demo

The character on the left is the embedded viewer — the floating layer itself iscompletely invisible at rest(only the border and shadow appear when the pointer enters), so it looks as if the character is standing right on the page.Drag the character itself to move the whole panel， Drag with the right button to rotate the character. While the left button is held the page calls play3dmodelaction Formation_Pickup and restores it on release.

1. One container + two lines of script

<!-- data-ba3d-drag enables “left-drag the character to move the container” -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<script type="module">
  import { autoMount } from './dist/3d-viewer.min.js';  // self-contained single-file build, no importmap needed
  autoMount();
</script>

Some characters have downward-spreading clips such as “fall down / death”, so the embed default framing offset is 42 so the character does not leave the scene when the card is shorter or the motion is larger; in that case write data-ba3d-framing-offset — larger values move the view up and leave more space below. 

<!-- default 42 (no attribute needed) -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<!-- to move it further up: write the value explicitly (unit: container CSS pixels) -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     data-ba3d-framing-offset="70"
     style="width:420px;height:430px"></div>

<!-- no downward offset at all -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     data-ba3d-framing-offset="0"
     style="width:420px;height:430px"></div>

⚠️ Note: the same value behaves differently incontainers of different heights(it is converted to world units using the container height), so retry after changing the size.

3. Panel size: changing it by percentage scales everything proportionally

Framing-related config fields:

FieldDescription
renderer.framing "tight" = usethe real skinned contentfor centring (centring/grounding by the whole box is wrong and makes the character off-centre and floating)
renderer.framingReferenceHeight reference panel height. Camera parameters are computed once from it asfixed world units — so scaling the panel by percentage scales the whole view proportionally (character size and relative position change together). This example uses 430 (panel height)
renderer.framingOffsetY Vertical framing offset in CSS px (relative to the reference height); positive = framing down / content up. Falling clips push the content to the bottom, so 57px down balances the margins

So just change the container size proportionally — no other parameter needs touching:

<!-- original (reference) size -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<!-- scale 1.5× -->
<div ... style="width:630px;height:645px"></div>

<!-- scale down to 60% -->
<div ... style="width:252px;height:258px"></div>

<!-- or use percentages / responsive units -->
<div ... style="width:50vh;height:51vh"></div>

If the model looks too small or too large,do not edit the config — just scroll the wheel to zoom and you are done.

4. Interaction conventions

ActionBehaviour
Left button onthe modeldragmoves the whole container (requires data-ba3d-drag）
Right button onthe modeldragrotates the character (the left button no longer rotates)
Wheelzoom

Hold to count as “press”: 0.2s threshold

After pressing the left button on the modelit does not fire immediately — it waits first, and once held longer than pressHoldMs (default 200ms it counts as a press and then dispatches ba3d:press and starts dragging the container; releasing early counts as a click and dispatches ba3d:click without dragging.

This wayclicking once to trigger an action but dragging the panel away insteadcan no longer happen.

panel.addEventListener('ba3d:press', (e) => {
  // e.detail = { button, heldMs, thresholdMs, hit }   held long enough → trigger the action
});
panel.addEventListener('ba3d:click', (e) => {
  // e.detail = { button, heldMs, thresholdMs, hit }   short press → counts as a click
});

All press/release events are dispatched on the container asbubbling CustomEvents, so the page can listen directly:

panel.addEventListener('ba3d:pointerdown', (e) => {
  // e.detail = { button, hit }                        hit = whether the press was on the model (dispatched immediately, before the threshold)
});
panel.addEventListener('ba3d:pointerup', (e) => {
  // e.detail = { button, hit, pressedOnModel, pressed }
  //   pressed = whether the hold threshold was crossed this time (true = pressed / false = just a click)
});

5. Action hooks: play3dmodelaction([动作数组])

play3dmodelaction(['Formation_Pickup']);   // play the first clip that matches
play3dmodelaction(['A', 'B']);             // search in order, play the first one that exists
play3dmodelaction([3]);                    // an index works too
play3dmodelaction('Cafe_Idle');            // a single string works too
play3dmodelaction();                       // no argument → back to the default clip (random idle)

Matching: exact name → case-insensitive exact → “name contains” (case-insensitive). So 'Formation_Pickup' matches xxx_Formation_Pickup。

Action menu in the bottom-left control area

The dropdown at the top of the bottom-left control area is plain page code: it asks the viewer once for the clip list,and switching clips only goes through the global hook, never touching the model internals:

const sel = document.getElementById('animSel');
let current = null;

// 1) fill the menu with the clip list
for (const a of viewer.getAnimations()) {
  const o = document.createElement('option');
  o.value = a.name;
  o.textContent = a.name.replace(/^[^_]*_/, '');
  sel.appendChild(o);
}
// 2) listen to the viewer’s ba3d:action event to sync the selection (without reading viewer internals)
panel.addEventListener('ba3d:action', (e) => { sel.value = current = e.detail.name; });

// 3) switching = call the global hook (returns the clip name actually played)
sel.addEventListener('change', () => {
  const played = play3dmodelaction([sel.value]);
  if (played) current = played;
});

Left-button press/release uses the same current, so “press triggers Pickup → release restores” restores exactly the clip you picked in the menu.

Test code on this page (what runs in the bottom-left log):

const panel = document.getElementById('floatPanel');
let prevAction = null;

// only ≥200ms counts as a “press”
panel.addEventListener('ba3d:press', (e) => {
  if (e.detail.button !== 0) return;
  prevAction = current;                                 // remember the menu selection
  play3dmodelaction(['Formation_Pickup']);              // press: trigger the action
});

// a short press counts as a click and does not trigger press
panel.addEventListener('ba3d:click', (e) => {
  console.log('点击，按住', e.detail.heldMs, 'ms / 阈值', e.detail.thresholdMs, 'ms');
});

panel.addEventListener('ba3d:pointerup', (e) => {
  if (e.detail.button !== 0 || !e.detail.pressed) return;   // restore only if it was really pressed
  play3dmodelaction(prevAction ? [prevAction] : undefined); // no argument = back to the default clip
});

6. Default clip

When the config has no animation.name , the viewerpicks one at random from clips whose name contains idle as the initial clip (this model has Normal_Idle / Cafe_Idle / Formation_Idle clips). Reload a few times and the initial clip changes.

7. Creating it from JS is equivalent

import { createViewer } from './dist/3d-viewer.min.js';

const viewer = createViewer(document.getElementById('floatPanel'), {
  modelUrl:       './assets/sample.glb',
  mouthAtlasUrl:  './assets/mouth/Character_Mouth_High.png',
  configUrl:      './assets/sample.json',   // you can also pass an object: config: {...}
  dragContainer:  true,              // left-drag on the model to move the container
  backgroundTransparent: true,
});
await viewer.load();
viewer.playAction(['Formation_Pickup']);

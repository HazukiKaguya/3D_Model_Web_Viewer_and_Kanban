3D 模型網頁內嵌看板娘演示

左邊那個角色就是內嵌的檢視器 —— 浮層本身平時完全隱形（滑鼠移進它的範圍才顯出邊框和投影）， 所以看起來就像角色直接站在網頁上。按住角色本體拖動可以移動整個面板， 按住右鍵拖動可以旋轉角色。按住左鍵時頁面會通過 play3dmodelaction 觸發 Formation_Pickup，鬆開恢復。

1. 放一個容器 + 兩行 script 就能用

<!-- data-ba3d-drag 開啟「左鍵按角色拖容器」 -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<script type="module">
  import { autoMount } from './dist/3d-viewer.min.js';  // 自包含單檔案版，無需 importmap
  autoMount();
</script>

有時候，我們會遇到角色有「倒地 / 死亡」這類向下展開的動畫，所以嵌入預設的取景偏移是 42，避免在卡片更矮或者動畫幅度更大時，角色部分跑出場景，這時在容器上寫 data-ba3d-framing-offset ，數值越大畫面越往上，下方留白越多。 

<!-- 預設 42（不用寫屬性） -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<!-- 想再往上一點：顯式寫數值（單位是容器的 CSS 畫素） -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     data-ba3d-framing-offset="70"
     style="width:420px;height:430px"></div>

<!-- 完全不下移 -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     data-ba3d-framing-offset="0"
     style="width:420px;height:430px"></div>

⚠️注意：同一數值在不同高度的容器裡效果不同（它按容器高換算成世界單位），所以換尺寸後要重新試一下。

2. 容器的 data-* 屬性

屬性說明
data-ba3d標記這個容器要掛檢視器
data-ba3d-config配置 JSON（模型 / 嘴部貼圖 / 基準 / 渲染 / 打光 / 背景）
data-ba3d-model模型檔案 URL（.glb）
data-ba3d-mouth嘴部修復貼圖 URL（.png）
data-ba3d-framing-offset取景垂直偏移（CSS 畫素 · 正值 = 取景下移 ⇒ 內容上移）。嵌入預設 42，角色有倒地/死亡這類向下展開的動畫時調大它，下方留白更多。
⚠️ 按容器高換算、換尺寸後要重試。用例見上面第 1 節。
data-ba3d-grid顯示地面網格（預設關 · 嵌入看板一般不需要）
data-ba3d-axes顯示原點 XYZ 座標軸（預設關）
data-ba3d-gizmo顯示視角指示器（預設關）
data-ba3d-light-helper顯示主光方向指示（預設關）
data-ba3d-drag開啟「左鍵按在模型上拖動整個容器」
data-ba3d-auto-rotatetrue 自動旋轉

3. 面板尺寸：按百分比改就是整體等比縮放

配置裡的取景相關欄位：

欄位說明
renderer.framing "tight" = 用真實蒙皮內容居中（整盒的居中/落地是錯的，會讓角色偏心 + 懸空）
renderer.framingReferenceHeight 參考面板高度。相機引數按它一次算成固定世界量 —— 於是面板按百分比縮放時，畫面整體等比縮放（角色尺寸和相對位置一起變）。本例選 430（面板高度）
renderer.framingOffsetY 取景垂直偏移，單位 CSS 畫素（以參考高度為準），正值 = 取景下移 / 畫面內容上移。倒地類動作會把內容壓在畫面下方，下移 57px 把上下餘量拉平

所以把容器尺寸按比例改一下就行，不需要動任何其它引數：

<!-- 原始（參考）尺寸 -->
<div data-ba3d data-ba3d-drag data-ba3d-config="./assets/sample.json"
     style="width:420px;height:430px"></div>

<!-- 放大 1.5 倍 -->
<div ... style="width:630px;height:645px"></div>

<!-- 縮小到 60% -->
<div ... style="width:252px;height:258px"></div>

<!-- 或者用百分比 / 響應式單位也行 -->
<div ... style="width:50vh;height:51vh"></div>

載入模型時若覺得太小/太大，不用改配置，直接滾動滾輪縮放模型即可。

4. 互動約定

操作行為
左鍵按在模型身上拖動移動整個容器（需 data-ba3d-drag）
右鍵按在模型身上拖動旋轉角色（左鍵不再旋轉）
滾輪縮放

按住才算「按下」：0.2s 閾值

左鍵在模型上按下後不會立刻觸發——先進入待定，按住超過 pressHoldMs（預設 200ms） 才真正算一次「按下」，這時才會派發 ba3d:press 並開始拖動容器； 沒按夠就鬆手算「點選」，派發 ba3d:click，不觸發拖動。

這樣點一下想觸發動作、結果把面板拖走了的情況就不會發生了。

panel.addEventListener('ba3d:press', (e) => {
  // e.detail = { button, heldMs, thresholdMs, hit }   按住夠久了 → 觸發動作
});
panel.addEventListener('ba3d:click', (e) => {
  // e.detail = { button, heldMs, thresholdMs, hit }   短按 → 算點選
});

所有按下/抬起都會在容器上派發冒泡的 CustomEvent，頁面直接監聽即可：

panel.addEventListener('ba3d:pointerdown', (e) => {
  // e.detail = { button, hit }                        hit=是否按在模型身上（立即派發，不過閾值）
});
panel.addEventListener('ba3d:pointerup', (e) => {
  // e.detail = { button, hit, pressedOnModel, pressed }
  //   pressed = 本次是否越過了按住閾值（true=按下過 / false=只是點選）
});

5. 動作鉤子：play3dmodelaction([动作数组])

play3dmodelaction(['Formation_Pickup']);   // 播第一個能匹配到的動作
play3dmodelaction(['A', 'B']);             // 按順序找，播第一個存在的
play3dmodelaction([3]);                    // 也可以用索引
play3dmodelaction('Cafe_Idle');            // 單個字串也行
play3dmodelaction();                       // 不傳 → 回到預設動作（隨機 idle）

匹配規則：精確名字 → 忽略大小寫精確 → 「名字包含」（忽略大小寫）。 所以 'Formation_Pickup' 能匹配到 xxx_Formation_Pickup。

左下角控制元件區的動作選單

左下角控制元件區最上面那行的下拉選單就是純頁面程式碼：動作列表問一次檢視器，切動作只走全域性鉤子， 完全不碰模型內部：

const sel = document.getElementById('animSel');
let current = null;

// 1) 用動作列表填充選單
for (const a of viewer.getAnimations()) {
  const o = document.createElement('option');
  o.value = a.name;
  o.textContent = a.name.replace(/^[^_]*_/, '');
  sel.appendChild(o);
}
// 2) 監聽檢視器的 ba3d:action 事件來同步選中項（不讀檢視器內部狀態）
panel.addEventListener('ba3d:action', (e) => { sel.value = current = e.detail.name; });

// 3) 切換 = 調全域性鉤子（返回值是實際播上的動作名）
sel.addEventListener('change', () => {
  const played = play3dmodelaction([sel.value]);
  if (played) current = played;
});

左鍵按下/抬起也用同一個 current，所以「按下觸發 Pickup → 抬起恢復」恢復的 正是你在選單裡選的那一段。

本頁測試程式碼（就是左下角日誌裡跑的那段）：

const panel = document.getElementById('floatPanel');
let prevAction = null;

// 按住 ≥200ms 才算「按下」
panel.addEventListener('ba3d:press', (e) => {
  if (e.detail.button !== 0) return;
  prevAction = current;                                 // 記住選單裡選的
  play3dmodelaction(['Formation_Pickup']);              // 按下：觸發動作
});

// 短按算點選，不觸發按下
panel.addEventListener('ba3d:click', (e) => {
  console.log('点击，按住', e.detail.heldMs, 'ms / 阈值', e.detail.thresholdMs, 'ms');
});

panel.addEventListener('ba3d:pointerup', (e) => {
  if (e.detail.button !== 0 || !e.detail.pressed) return;   // 只有真的按下過才恢復
  play3dmodelaction(prevAction ? [prevAction] : undefined); // 不帶參 = 回預設動作
});

6. 預設動作

配置裡沒寫 animation.name 時，會在名字含 idle 的動作裡隨機挑一個作為初始動作 （本模型有 Normal_Idle / Cafe_Idle / Formation_Idle 三個）。 多重新整理幾次能看到初始動作在變。

7. 也可以用 JS 建立（等價）

import { createViewer } from './dist/3d-viewer.min.js';

const viewer = createViewer(document.getElementById('floatPanel'), {
  modelUrl:       './assets/sample.glb',
  mouthAtlasUrl:  './assets/mouth/Character_Mouth_High.png',
  configUrl:      './assets/sample.json',   // 也可直接傳物件：config: {...}
  dragContainer:  true,              // 左鍵按模型拖容器
  backgroundTransparent: true,
});
await viewer.load();
viewer.playAction(['Formation_Pickup']);
